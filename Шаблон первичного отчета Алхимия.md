# Структурный шаблон: первичный отчёт «Алхимия Души»

Главный стандарт: `MASTER_REPORT_INSTRUCTIONS.md`.

Формат: полный персональный A4 PDF. Объём определяется исходным текстом пользователя; содержательный текст не сокращать ради числа страниц.
Стиль: ясный, тёплый, персональный. Сохранять голос и формулировки пользователя.
Логика: Диагностика → Вывод диагностики → Поддержка и назначение → Интеграция и сопровождение → Итог / метафора этапа.

## Визуальная подача

По умолчанию — светлая форма «Алхимия Души / Маяк»: кремовый фон, глубокий синий, золото, тонкие рамки, заметный мотив маяка / луча / горизонта, крупная типографика, много воздуха без уменьшения основного текста.

Перед выдачей пройти `Чек-лист первичного отчета Алхимия.md`.
