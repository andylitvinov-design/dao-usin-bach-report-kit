# DAO / У-Син / Алхимия Души — Report Kit

Набор структуры и правил для красивых персональных PDF-отчётов.

## С чего начинать агенту

**Всегда сначала читать:** `MASTER_REPORT_INSTRUCTIONS.md`.

Это главный стандарт. Он определяет:
- как сохранять исходный текст пользователя;
- что нельзя придумывать;
- выбор светлой формы «Алхимия Души / Маяк» или тёплой DAO-формы;
- типографику и визуальную композицию;
- структуру первичного, У-Син и повторного отчётов;
- обязательную проверку PDF перед выдачей.

## Структурные шаблоны

- `Шаблон первичного отчета Алхимия.md` — обычный полный первичный отчёт.
- `Шаблон первичного отчета УСИН.md` — отчёт по пяти стихиям + DAO.
- `Шаблон повторного отчета Алхимия.md` — динамика: изменения → было/стало → переход → новая задача.
- `Чек-лист первичного отчета Алхимия.md` — финальный QA текста, дизайна и PDF.

HTML-файлы `report-primary-*` и `report-repeat-*` считать историческими / техническими примерами, а не источником актуальных ограничений по объёму.

## Визуальные референсы

### Основной
Светлая форма **«Алхимия Души / Маяк»**:
- кремовый фон;
- глубокий синий;
- золото;
- тонкие рамки;
- крупная, комфортная типографика;
- много воздуха;
- заметный мотив маяка / луча / горизонта;
- художественная editorial-композиция.

Рабочий ориентир конструктора:
`https://psitherapy.vercel.app/report-builder.html`

### DAO / тёплая форма
GitHub reference:
`https://github.com/andylitvinov-design/report/tree/6bbaa3f`

Использовать для архетипических, алхимических и глубоко У-Син материалов либо как источник декоративных приёмов для основной формы.

## Главное правило содержания

**Текущий текст пользователя — источник истины.**

Не сокращать его ради компактности. Не превращать в сухой корпоративный пересказ. Не придумывать диагнозы, препараты, дозировки или медицинские обещания. Если текста много — увеличить число страниц и сохранить удобный размер шрифта.

## Главное правило дизайна

PDF должен выглядеть как персональный красивый отчёт, а не как веб-интерфейс или набор белых карточек. Графическая составляющая обязательна и должна быть заметной, но не мешать чтению.

## Финальная выдача

Перед выдачей пройти чек-лист и визуально проверить каждую страницу: текст, размер шрифта, обрезания, наложения, пустые страницы, сохранность авторского содержания и графическую выразительность.
