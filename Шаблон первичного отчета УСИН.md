## 4. ПОДДЕРЖКА И НАЗНАЧЕНИЕ

Группировать средства по стихиям или по приоритету — выбирается тот вариант, который яснее отражает пользовательский текст.

Для каждого средства показывать:
- название;
- соответствующую стихию, если дана;
- значение / эффект, который указал пользователь;
- приоритет;
- схему применения только если она есть в исходном тексте.

Никаких придуманных дозировок, диагнозов или лечебных обещаний.

## Визуальная подача

По умолчанию использовать светлую «Алхимию Души / Маяк», сохраняя цветовые обозначения стихий как небольшие смысловые акценты. Если материал глубоко архетипический и алхимический — допустима тёплая DAO-форма.

Основной текст не мельче комфортного A4-уровня; при большом объёме добавлять страницы.
