# Структурный шаблон: повторный отчёт «Алхимия Души»

Главный стандарт: `MASTER_REPORT_INSTRUCTIONS.md`.

Формат: персональный A4 PDF с акцентом на динамику. Не сокращать авторский текст ради лимита страниц.
Логика: Изменения → Было / стало → Переход стадии → Смена средств → Смысл изменений → Задача периода → Рекомендации → Итог → Метафора нового этапа.

## 1. ЧТО ИЗМЕНИЛОСЬ

Период: [предыдущая дата] → [текущая дата]

[Сохранить пользовательский текст о фактических изменениях, а не сводить его автоматически к 2–3 пунктам.]

## 2. БЫЛО / СТАЛО

### Ресурс «Я»
Было: [значение / состояние]
Стало: [значение / состояние]

### Другие показатели
[Все сравнения, которые пользователь дал и считает существенными.]

Визуально лучше показать это как 2 крупные колонки или спокойную шкалу перехода, а не плотную таблицу.

Из: [предыдущая стадия]
В: [текущая стадия]

[Что означает этот переход по тексту пользователя.]

## Визуальная подача

Повторный отчёт должен визуально показывать движение. Использовать крупные «было → стало», линию или шкалу перехода, смену акцентов и финальный образ. Не делать отчёт набором одинаковых карточек.

Основной текст держать крупным и комфортным; при необходимости увеличивать число страниц.

Перед выдачей пройти `Чек-лист первичного отчета Алхимия.md`.
