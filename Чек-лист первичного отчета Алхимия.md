# Чек-лист качества PDF-отчёта «Алхимия Души»

Использовать перед каждой выдачей клиенту. Главный стандарт: `MASTER_REPORT_INSTRUCTIONS.md`.

## 1. Сохранение исходного текста

- [ ] Все существенные смысловые фрагменты исходного текста пользователя присутствуют в отчёте.
- [ ] Не потеряны числа, значения ресурса, названия стадий, переходов и средств.
- [ ] Авторские формулировки сохранены там, где они важны для смысла и голоса текста.
- [ ] Нет пересказа большого авторского абзаца одной общей фразой только ради компактности.
- [ ] Удалены только явные повторы, служебные вводные и опечатки.
- [ ] Ничего медицинского не придумано от агента: диагнозы, препараты, дозировки, обещания результата.

## 2. Структура

- [ ] Есть ясная линия: Диагностика → Вывод → Поддержка / назначение → Интеграция / сопровождение.
- [ ] Показан текущий ресурс и стадия / переход, если они есть в исходном тексте.
- [ ] Основные и дополнительные средства визуально различаются.
- [ ] Есть понятный итог: что происходит сейчас и к чему идёт движение.
- [ ] Есть общая метафора текущего этапа, если она уместна по материалу.

## 3. Читаемость

- [ ] Основной текст визуально не мелкий; ориентир 11.5–13 pt на A4.
- [ ] На телефоне PDF можно читать без постоянного увеличения.
- [ ] Межстрочный интервал комфортный, текст не спрессован.
- [ ] Нет чрезмерно длинных строк и плотных таблиц.
- [ ] Если текста много, добавлена страница, а не уменьшен шрифт.

## 4. Графическая составляющая

- [ ] Отчёт визуально узнаваем как «Алхимия Души», а не как обычный офисный документ.
- [ ] Есть заметный художественный мотив: маяк / луч / горизонт либо тёплая DAO-графика.
- [ ] Есть тонкие рамки, золотые акценты и глубокий синий либо соответствующая DAO-палитра.
- [ ] Есть 2–4 повторяющихся графических мотива, создающих цельность.
- [ ] Ключевая формула / переход / метафора выделены визуально.
- [ ] Графика поддерживает содержание и не заменяет его.
- [ ] Нет ощущения набора однотипных белых карточек.

## 5. Композиция страниц

- [ ] У каждой страницы есть визуальный центр и понятная иерархия.
- [ ] Нет слишком больших пустых зон при одновременно мелком тексте.
- [ ] Нет перегруженных страниц.
- [ ] Заголовок не остаётся один внизу страницы.
- [ ] Карточки и декоративные элементы не разрывают логически связанный текст.

## 6. Техническая проверка PDF

- [ ] Каждая страница просмотрена после финального рендера.
- [ ] A4 portrait отображается корректно.
- [ ] Нет обрезанного текста.
- [ ] Нет наложений текста и графики.
- [ ] Нет элементов за пределами страницы.
- [ ] Нет пустой финальной страницы.
- [ ] Шрифты и кириллица отображаются корректно.
- [ ] PDF открывается без ошибок.

## 7. Финальный контроль

Перед отправкой задать три вопроса:

1. Узнает ли пользователь в отчёте свой собственный текст и мысли?
2. Выглядит ли документ как красивый персональный отчёт, а не шаблон с мелким текстом?
3. Стало ли содержание яснее благодаря дизайну, не потеряв глубины?

Если хотя бы один ответ «нет» — доработать PDF перед выдачей.
